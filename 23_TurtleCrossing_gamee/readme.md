# Turtle Crossing

## Introduction

This project is a game in which the player controls a turtle that must cross to the other side without getting hit by cars.
Reaching the other side takes the player to the next level, in which the speed is increased.

## Controls

* Up Arrow Key - Move the turtle up.

## Dependencies

* car_manager.py - This file generates cars for each level.
* player.py - This file is in charge of player movement.
* scoreboard.py - This file tracks the level on which the player is on.
